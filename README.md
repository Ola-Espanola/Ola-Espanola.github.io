# Ola-Espanola.github.io
Digital Nomad Visa in Spain — practical guide / Виза цифрового кочевника в Испании

Публичные страницы — статические HTML-файлы. При правках синхронизируйте текст с источником в `content/`: поля `title`, `description` и `canonical` в начале Markdown соответствуют метаданным HTML, а заголовок первого уровня — видимому заголовку страницы. Автоматической сборки из Markdown нет.

Для поиска используйте конкретные заголовки и описания по теме страницы, без скрытых ключевых слов. При изменении метаданных обновляйте также `og:title`, `og:description` и `og:url`. Новую публичную страницу добавляйте в `sitemap.xml` и связывайте с подходящим разделом сайта.

## Общая шапка и левое меню

Общие части редактируются в одном месте:

- `partials/brand.html` — оба символа и название сайта, включая вариант для калькулятора.
- `partials/header.html` — шапка, подпись и верхняя кнопка.
- `partials/calculator-header.html` — компактная шапка калькулятора.
- `partials/sidebar.html` — разделы и ссылки левого меню.

После изменения этих файлов запустите `update-layout.cmd` двойным щелчком в Windows или выполните из папки репозитория:

```text
node scripts/update-layout.cjs
```

Нужен Node.js 18 или новее. Устанавливать пакеты не требуется. Скрипт обновляет готовые `index.html`, `docs/*.html` и `blog/*.html` прямо в репозитории. Сохраняйте в одном коммите общие файлы и получившиеся HTML. Скрипт выполняется до публикации; браузер посетителя получает готовую шапку и меню.

Для просмотра откройте `index.html` или любую страницу из `docs/` и `blog/` обычным способом. Ссылки в общей шапке и меню, а также пути к их картинкам относительные и работают с диска. Подсветка текущего пункта определяется автоматически при обновлении.

Скрипт меняет только участки между комментариями `<!-- shared:... -->` и `<!-- /shared:... -->`. Текст статьи редактируется в самой странице, как раньше. Не правьте сгенерированные шапку и меню внутри этих границ: следующее обновление заменит их содержимое. До записи скрипт проверяет все страницы, чтобы ошибка в шаблоне или границах блока не оставила частично обновлённый сайт.

При добавлении страницы скопируйте подходящую существующую страницу вместе с комментариями. Для обычной шапки используется `shared:header`, для калькулятора — `shared:calculator-header`. У меню вариант `shared:sidebar guide` включает раздел «Документы». Варианты `shared:sidebar blog-N` показывают первые N ссылок на статьи из блоков `{{#blog1}}` … `{{#blog5}}` общего меню: так сохранены прежние различия между страницами блога. `blog-0` используется на странице списка статей. Блок `{{#guide}}` … `{{/guide}}` показывается только в гайдах. Калькулятор использует то же меню `shared:sidebar guide`, что и страницы гайдов.

В общих файлах внутренние адреса пишутся от корня сайта, например `/docs/pricing.html` или `/assets/images/site-symbol.png`. Скрипт сам превращает их в относительные пути для каждой страницы. Для главной и списка блога используются явные `index.html`, чтобы работали переходы с диска. Адреса опубликованных страниц и их canonical не меняются.

Проверка без записи и проверка работы обновления:

```text
node scripts/update-layout.cjs --check
node --test scripts/update-layout.test.cjs
```

Если шаблоны и HTML расходятся, `--check` завершится с ошибкой и покажет страницы, требующие обновления. Файлы в `partials/`, `scripts/` и `update-layout.cmd` исключены из публикации через `_config.yml`.
