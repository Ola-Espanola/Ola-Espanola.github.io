# Налоговый калькулятор для цифровых кочевников в Испании

Страница-калькулятор для предварительной оценки налогов и минимального дохода по DNV на 2026 год. Страница намеренно не добавлена в меню и sitemap и должна открываться только по прямой ссылке.

## Параметры

- формат работы: autónomo / работа в найме;
- доход до налогов в месяц;
- количество человек в заявке;
- расходы autónomo;
- для работы в найме: обычный IRPF / специальный режим Beckham.

## Порог DNV

Используется годовой SMI 2026: 17 094 EUR. Для сопоставимого месячного дохода сумма делится на 12: 1 424,50 EUR.

Формула:

- основной заявитель: 200% SMI = 2 849 EUR в месяц;
- первый член семьи: +75% SMI;
- каждый следующий член семьи: +25% SMI.

## Autónomo

Для оценки cuota используется таблица RETA 2026 и минимальная база соответствующего tramo. Суммарная ставка: 31,5%.

Для определения tramo расчетный rendimiento neto уменьшается на 7%. Вводимые пользователем расходы считаются расходами, допустимыми к вычету, без самой cuota Seguridad Social.

Обычный IRPF оценивается по условной общей прогрессивной шкале 19% / 24% / 30% / 37% / 45% / 47% с базовым личным минимумом. Это оценка: реальная автономная часть зависит от Comunidad Autónoma и индивидуальных обстоятельств.

## Работа в найме

При обычном IRPF учитывается стандартный расход 2 000 EUR по трудовым доходам. Испанские социальные взносы принимаются равными нулю, если у работника есть действующее подтверждение социального страхования в стране работодателя.

При выборе режима Beckham применяется ставка 24% до 600 000 EUR в год и 47% к превышению. Право на специальный режим нужно проверять отдельно.

## Ограничения

Количество членов семьи используется только для порога DNV. Калькулятор не моделирует налоговые минимумы и вычеты на детей, супруга, совместную декларацию, инвестиционные доходы, иностранные налоги и их зачет, региональные льготы и другие индивидуальные обстоятельства.

## Официальные источники

- BOE: Real Decreto 126/2026 — SMI 2026.
- UGE: требования к экономическим средствам для teletrabajadores.
- Seguridad Social: таблица RETA 2026.
- BOE: Ley 35/2006, artículo 93 — специальный режим для desplazados.
